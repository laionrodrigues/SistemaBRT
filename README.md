# Modernização do Sistema BRT 🚍

Sistema desenvolvido em Java para gerenciamento de um sistema de transporte BRT.

O projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos e desenvolvimento de aplicações em Java.

## Funcionalidades

O sistema permite o gerenciamento de:

- Passageiros
- Motoristas
- Cobradores
- Ônibus
- Terminais
- Rotas

Também possui validação de dados e tratamento de exceções durante os cadastros.

## Conceitos utilizados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Herança
- Encapsulamento
- Abstração
- Construtores
- ArrayList
- Métodos e atributos
- Validação de dados
- Tratamento de exceções
- Organização em diferentes classes

## Tecnologias

- Java
- Maven
- IntelliJ IDEA
